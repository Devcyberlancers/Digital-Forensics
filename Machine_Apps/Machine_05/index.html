Sleuth Kit Command Primer

This machine uses a disk image, not normal loose files. Sleuth Kit tools read the image like an investigator would read a captured drive.

  1. Offset means the sector where the filesystem starts inside the disk image. You discover it with mmls, then reuse it with -o <OFFSET>.
  2. Metadata address is the file record number printed by fls before the colon. Use that number with istat to inspect metadata or icat to extract content.
  3. Redirection with > saves extracted output into a file in your Working folder.
  4. Workflow order: use mmls to find the offset, fls to find files, istat to prove timestamps, and icat to recover file contents.

Command Cheat Sheet

  1. mmls "$IMG" - read the partition table and find the filesystem start sector.
  2. fls -r -p -o <OFFSET> "$IMG" - recursively list files with full paths; the number before : is the metadata address.
  3. istat -o <OFFSET> "$IMG" <ADDRESS> - inspect timestamps and metadata for one file record.
  4. icat -o <OFFSET> "$IMG" <ADDRESS> > Working/name - extract file contents from the image.
  5. fls -r -d -p -o <OFFSET> "$IMG" - show deleted entries for recovery questions.
  6. od -An -tx1 -N16 file - view the first 16 bytes in hex for header analysis.
  7. unzip -l archive.zip lists archive contents; unzip -p archive.zip file prints a recovered file.

Flag normalization: use lowercase, remove spaces/underscores/hyphens/file extensions, and convert times like 21:12:41 to 211241.
