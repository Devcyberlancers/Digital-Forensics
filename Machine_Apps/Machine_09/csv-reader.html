How to use this reader

Choose the CSV from your existing Evidence/Tables folder. Each column has a filter and a matching mode. Filters work together. Click a column heading to sort its text values. Changing a filter clears previous selections.

Choose a numeric column, then select matching rows to sum that column. Compare peer groups by changing the peer filter yourself. This reader does not decide which records belong in the investigation or construct any flags.

All processing stays inside this page. Source files are never modified. IDs, phone numbers and hexadecimal values remain text.
